# Vault Coach

> 语言版本：[English](./README.md) | 中文

**把 Obsidian 知识库变成可持续的学习流程：** 建立可追溯的知识库、进行结构化考试、审核概念关系，并通过学习图谱查看已掌握与待巩固的知识。

Vault Coach 是面向学习者、研究者和知识型团队的 Obsidian 插件。它支持 Markdown 与文本型 PDF、带引用的问答、限定范围的练习考试、可审核的概念图谱，以及基于考试证据的掌握度追踪。

## Vault Coach 解决什么问题？

笔记只有在能够被重新理解、检验和建立联系时，才能真正转化为知识。Vault Coach 将这一学习闭环放进你已经在使用的 Vault：

1. **查找并理解**：向 Markdown 笔记和文本型 PDF 提问，并检查回答依据。
2. **练习并评估**：从整个 Vault、目录或指定文件生成考试，提交答案并保存结构化结果。
3. **建立概念连接**：提取带证据的概念与关系候选，并在概念审核中决定哪些关系真正成立。
4. **浏览学习状态**：在学习图谱中探索已确认的知识结构，在学习仪表盘中查看有证据支撑的掌握度。
5. **掌控数据去向**：你可以选择本地模型、自托管接口或 OpenAI 兼容服务；只有你配置并主动使用的功能才会发起模型调用。

## 核心能力

### 建立个人知识库

你可以选择扫描整个 Vault 或某个目录。Vault Coach 会索引 Markdown，以及可选的带原生文本层 PDF；它在切分检索内容时保留标题、路径、摘录和 PDF 页码，以便回答可追溯。

- 关键词、向量和混合检索
- 可选的 Query Rewrite 与 Rerank
- 文本型 PDF 的页码级来源引用
- 日常文件变更的自动增量同步
- 可配置的 PDF 限制与切分策略
- 可选的本地长期记忆，用于保存对话中的持久信息，并可在设置中关闭

### 用考试模式进行知识训练

考试模式会把指定知识转化为刻意练习，而不只是再开启一个聊天窗口。你可以选择整个知识库、若干目录或单个文件，检查并调整包含文件，生成题目、提交答案并查看评分反馈。

- 按当前学习材料限定考试范围
- 为当前考试保留包含/排除选择
- 过滤 TODO、日志、链接索引、占位笔记和草稿等低价值内容
- 先规划知识覆盖，再生成题目与评分反馈
- 在本地保存结构化 Assessment 记录；需要时导出可读 Markdown 报告

### 将笔记转化为可审核的概念图谱

可选的**语义概念图谱**会从已索引的 Section 中提取概念和关系候选。它遵循“先审核、后生效”的原则：

- 每个候选关系都保留来源证据。
- 虚线表示候选关系；已确认关系是独立的事实。
- 你可以确认、拒绝、撤销决策、合并概念、维护别名，以及新增或删除手工关系。
- 相似概念候选使用有上限的近似近邻查询；相似度不会自动合并概念。
- 模型驱动的语义重建始终需要明确执行，不会因为打开 Obsidian 而静默发生。

### 在学习图谱中探索已确认知识

**学习图谱**是面向阅读和探索的图谱视图，只展示已确认关系与用户创建关系；具有方向的关系会以箭头呈现。你可以搜索、筛选关系类型、缩放/拖动画布、聚焦邻域、检查来源证据，并跳回原始笔记。

待确认或已拒绝的候选不会进入学习图谱，因此视觉上的连接不会被误解为已确认的学习事实。可选的高置信自动关系会以不同样式呈现，且仅用于展示，不影响考试或掌握度。

### 跟踪有证据的掌握度

**学习仪表盘**汇总已确认概念、考试覆盖率、掌握度分布和本地数据健康状态。掌握度来自已保存的结构化考试事件与已确认的概念绑定，而不是仅凭“读过一篇笔记”进行猜测。

在完成考试或大幅调整有效概念图谱后，可执行 **重建概念掌握度**。掌握度快照可随时重建，而已保存的考试 Session 始终是学习记录的事实来源。

## 安装

### 从 Obsidian 社区插件安装

当 Vault Coach 已进入社区插件目录后：

1. 在 Obsidian 中打开 **设置 → 社区插件**。
2. 如 Obsidian 提示，请关闭受限模式。
3. 点击 **浏览**，搜索 **Vault Coach**，然后安装并启用。

### 从 Release 手动安装

1. 从对应的 [GitHub Release](https://github.com/Wanjin5508/vault-coach/releases) 下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 创建 `<你的-vault>/.obsidian/plugins/vault-coach/` 目录。
3. 将以上三个文件放入该目录。
4. 重新加载 Obsidian，然后在 **设置 → 社区插件** 中启用 **Vault Coach**。

除非已经自行构建，否则不要直接把源代码 ZIP 当作插件 Release 安装。

## 快速开始

### 1. 安装并打开 Vault Coach

1. 在 Obsidian 中安装并启用 Vault Coach。
2. 点击 Ribbon 图标，或在命令面板运行 **在右侧打开 VaultCoach**。
3. 打开 **设置 → Vault Coach**。

### 2. 选择要训练的知识范围

![alt text](assets/screenshots/setting-kb.png)

在 **知识库** 设置中：

1. 选择 **整个 Vault** 或 **指定目录**。
2. 启用 Markdown 索引；如有需要，再启用文本型 PDF 索引。
3. 按知识库规模设置 PDF 限制与 Chunk 参数。
4. 在侧栏点击 **重建索引**。

构建完成后，先提出一个问题，确认显示的来源确实来自你预期的笔记。

### 3. 配置模型服务

Vault Coach 不要求使用某一种模型服务。请分别选择适合自己环境的聊天与 Embedding 提供方：

| 选项 | 适用场景 |
| --- | --- |
| 本地 Ollama | 希望模型工作流完全在本机运行，并且设备可运行合适的聊天/Embedding 模型。 |
| OpenAI 兼容接口 | 使用云服务、自托管网关或其他兼容服务；需要显式填写地址、模型与 API Key。 |
| 仅关键词检索 | 不构建 Embedding，但仍希望获得基础本地搜索能力。 |

![alt text](assets/screenshots/setting-model.png)

Ollama 是一条可选的隐私部署路径，并不是使用插件的前提。如果使用 Ollama，常见基础地址是 `http://127.0.0.1:11434`；请不要在地址末尾添加 `/api/chat`、`/api/embed` 或 `/api/embeddings`。

### 4. 开始一次学习闭环

1. 先提出一个带引用的问题，快速复习主题。
2. 切换到 **考试模式**，创建一个短小且范围明确的测试。
3. 提交答案并查看反馈。
4. 打开 **概念审核**，确认或修正重要关系。
5. 打开 **学习图谱** 与 **学习仪表盘**，查看已确认知识结构与掌握度证据。

这套流程适用于面试准备、证书学习、课程复习、论文阅读和项目上手。

## 功能使用说明

### 提问并检查来源

1. 在侧栏选择 **问答模式**。
2. 选择关键词、向量或混合检索。
3. 输入一个聚焦的问题。
4. 展开回答下方的来源，查看摘录、标题或 PDF 页码。
5. 点击来源链接，回到对应笔记。

建议：

- 当 Vault 包含多个领域时，先使用范围更窄的问题。
- 需要隔离项目时，将知识库范围设为特定目录。
- 启用向量检索前，请先配置 Embedding 服务并重建索引。

### 创建、完成并复盘考试

1. 切换到 **考试模式**。
2. 选择完整知识库、一个或多个目录，或从学习图谱启动一个“按来源范围”的考试。
3. 点击 **管理文件**，逐个包含或排除文件。
4. 如需检查可出题材料，先运行 **分析考试范围**。
5. 设置题目数量并点击 **生成考试**。
6. 提交答案，查看结果后使用 **保存结果** 或 **导出**。

已保存的 Assessment 事实位于 `.vault-coach/assessments/`。它们是本地 Vault 数据；重建索引或刷新图谱不会删除这些记录。

### 构建和审核语义图谱

1. 在设置中启用 **语义概念图谱**，并检查当前模型服务配置。
2. 先重建普通知识索引。
3. 在命令面板运行 **重建语义概念图谱**。
4. 运行 **打开概念审核**。
5. 结合证据审核候选关系；必要时确认、拒绝、合并或创建手工关系。
6. 运行 **打开学习图谱**，探索已确认的结果。

请有意识地执行语义图谱重建：它可能会向你选择的聊天模型发送已索引的 Section 摘录，并向选择的 Embedding 服务发送简短概念文本。具体发送到本机、私有服务还是远程服务，取决于你的模型设置。

### 使用学习图谱和仪表盘

1. 在命令面板运行 **打开学习图谱**。
2. 搜索或筛选关系后，点击节点或边。
3. 使用 **聚焦邻域** 查看局部关系；使用 **重置探索** 回到更广的投影。
4. 只有在需要文档/Section/标签上下文时，才开启 **显示来源结构**。
5. 运行 **打开学习仪表盘**，查看考试覆盖率和掌握度分布。
6. 在完成新考试或修改概念审核结果后，运行 **重建概念掌握度**。

### 当插件关闭期间知识库发生变化

每次成功索引后，Vault Coach 都会保存一份轻量的来源清单。若在插件关闭期间增加、删除、替换文件，或修改知识库范围，插件不会把旧索引、旧图谱或旧掌握度快照当作当前数据继续使用。

1. 侧栏、学习图谱和仪表盘会显示需要更新的提示。
2. 点击 **重建索引**。
3. 如果知识库主体发生大规模替换，请在查看影响数量后，按需运行 **重置语义图谱人工决策**。
4. 运行 **查看 VaultCoach 派生数据存储用量**，按类别检查本地存储占用。

重建不会删除原始笔记、已保存的 Assessment Session 或已导出的报告；它只会替换可重建的派生数据，例如索引、向量、图谱快照和掌握度快照。

## 命令面板速查

| 命令 | 用途 |
| --- | --- |
| **重建知识索引** | 重新扫描当前知识范围，并重建检索数据。 |
| **清除知识索引** | 清除可重建的索引与图谱数据；已保存考试记录会保留。 |
| **重建语义概念图谱** | 显式执行模型驱动的概念/关系抽取。 |
| **打开概念审核** | 审核概念候选，并做可撤销的人工治理决策。 |
| **打开学习图谱** | 浏览已确认的知识图谱。 |
| **打开学习仪表盘** | 查看概念、考试与掌握度摘要。 |
| **重建概念掌握度** | 根据考试证据重新计算本地掌握度读模型。 |
| **重置语义图谱人工决策** | 在明确审核后清除人工语义决策。 |
| **查看 VaultCoach 派生数据存储用量** | 只读查看 VaultCoach 管理的本地数据分类占用。 |

## 隐私、存储与网络使用

Vault Coach 没有隐藏遥测。它将工作数据保存在当前 Vault 的 `.vault-coach/` 和插件配置目录中。

| 数据 | 保存原因 | 重建索引时的行为 |
| --- | --- | --- |
| 文本/向量索引与图谱快照 | 加速检索和图谱渲染 | 根据当前知识范围重新构建 |
| 语义候选、Embedding 与审核决策 | 支持概念审核和学习图谱 | 失效的来源派生数据会被对齐；人工决策需要显式重置 |
| 掌握度快照 | 加速仪表盘读取 | 可由考试证据与有效概念图重新生成 |
| Assessment Session 与导出报告 | 保存学习历史 | 保留 |

网络行为完全由模型设置控制：

- 使用本地 Ollama 时，模型请求只会发往你配置的本地地址。
- 使用 OpenAI 兼容提供方时，该服务可能收到你主动运行功能所必需的文本，例如问答的检索上下文、考试材料与答案、或语义抽取的 Section 摘录。
- 确定性结构图和来源清单对比不会调用模型，也不会访问网络。

请将 `.vault-coach/` 视为私有 Vault 数据。其中可能包含笔记摘录、文件名、标题、答案、反馈、图谱证据和模型元数据。除非已经审核内容，否则不要把它提交到公开仓库。

## 当前限制

- PDF 支持面向带原生文本层的文件，暂不包含扫描型 PDF 的 OCR。
- 复杂 PDF 表格、图表、公式和多栏排版可能需要人工核对。
- 考试生成和评分是由你配置的模型提供的学习辅助，不是权威评分。
- 概念抽取质量取决于源材料和所选模型；人工审核是产品设计的一部分，而不是失败兜底。
- 大型知识库可能暂停新的本地语义计算，以保护 Obsidian 界面；既有索引、问答、考试和已确认图谱读取仍然可用。
