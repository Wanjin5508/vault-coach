# RAG 检索、排序与回答质量参数

## 1. 当前检索漏斗

当前默认候选规模为 keyword TopK=10、vector TopK=10、hybrid TopK=12、rerank TopK=8、context TopK=8、最终来源上限=5，RRF 常数 `k=60`。这些值决定漏斗宽度，必须联合评估质量、延迟和上下文长度。

## 2. 核心离线指标

设查询的相关 chunk 集合为 R，前 K 个检索结果为 A(K)：

### Recall@K

```text
Recall@K = |R ∩ A(K)| / |R|
```

表示所有相关证据中有多少进入前 K。RAG 第一阶段最关注 Recall，因为证据没有被召回，后续 rerank 和 LLM 无法补救。当前 M4 建议中、英、德 Recall@10 均不低于 0.80，但协议尚未批准。

### Precision@K

```text
Precision@K = |R ∩ A(K)| / K
```

表示前 K 中相关结果的比例。上下文窗口有限时 Precision 很重要。若某查询相关项少于 K，Precision@K 的理论上限也可能低，因此要结合 Recall 看。

### Hit Rate@K / Success@K

前 K 至少出现一个相关结果则该查询得 1，否则 0。适合“找到任一证据即可回答”的场景，但不能衡量多个证据是否找全。

### MRR

```text
RR(q) = 1 / 第一个相关结果的排名
MRR = 所有查询 RR 的平均值
```

第一个正确证据越靠前越好。当前 M4 建议每种语言 MRR ≥ 0.60。MRR 不关心第二个以后相关结果，不能替代 Recall。

### nDCG@K

nDCG 使用分级相关性和排名折损，适合标注 `完全相关/部分相关/无关` 的 rerank 评估。结果范围 0–1，1 表示与理想排序一致。只有二元相关标签时仍可使用，但信息量少于分级标签。

## 3. 无答案与准入指标

数据集必须包含 Vault 中没有答案的问题。记录无答案查询的 Top1 score 分布、误接纳率 FPR、正确拒答率 TNR 和答案覆盖率。相似度阈值应根据 ROC/PR 曲线或明确成本选择，不能凭单个例子决定。

## 4. 分阶段诊断

| 阶段 | 主要比较 |
|---|---|
| Keyword | 中文/英文/德文词形、短语、标题加权 |
| Vector | Recall、跨语言查询、维度、归一化、无答案分数 |
| Hybrid | 相对 keyword/vector 的增益，RRF 参数敏感性 |
| Query rewrite | 原查询与改写查询的 Recall 差值、语义漂移率、额外延迟 |
| Rerank | nDCG/MRR 增益、相关结果降级率、P95 延迟 |
| Context selection | 证据覆盖率、重复率、字符/token 预算 |

必须保存每个查询的原始 Top10 排名，平均分无法定位退化案例。

## 5. 回答级指标

- **答案正确性**：与金标事实的一致程度；人工评分或经过验证的 evaluator。
- **Faithfulness/忠实度**：答案中的可验证陈述能否由提供的上下文支持。
- **Citation precision**：引用中真正支持对应陈述的比例。
- **Citation recall**：应引用的关键陈述中实际有引用的比例。
- **拒答准确率**：无证据时正确拒答的比例。
- **语言遵循率**：回答语言符合用户选择的比例。

LLM-as-judge 必须固定模型、版本、prompt 和温度，并用人工双标子集校验。它是近似评估器，不能被写成客观真值。

## 6. 分层报告

至少按语言、答案/无答案、Markdown/PDF、短/长问题、单跳/多证据、同语言/跨语言分层。总体均值通过而某一语言失败时，整体不能直接判定 GO。
