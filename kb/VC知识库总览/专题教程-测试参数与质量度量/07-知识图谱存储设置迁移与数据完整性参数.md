# 知识图谱、存储、设置迁移与数据完整性参数

## 1. 确定性图和语义图

图快照必须满足：节点/边 ID 唯一、引用端点存在、Section 归属有效、隐藏路径不泄漏、规范化 ID 正确、节点/边/source 排序稳定、统计值与实体数量一致。完整性问题数应为 0。

语义抽取还要衡量 concept precision/recall、关系 precision/recall、别名合并误差、候选接受率、人工否决率和 provenance 完整率。模型提出的候选关系不能直接计为确认事实。

## 2. 图容量和渲染

当前 Lite 自动构建最多 400 个语义输入窗口；401–650 需要人工确认；超过 650 拒绝 Lite 构建。诊断警告还包括 10 MiB 语义字符、8,000 chunks、1,000 sections、2,000 concepts、10,000 语义关系和 128 MiB 原始 float32 向量。

Learning Map 默认投影 150 nodes/300 edges，完整交互上限 500 nodes/2,000 edges。测试记录构建耗时、查询 P95、首次渲染、交互帧时间、峰值内存、截断是否稳定和大图降级提示是否正确。

## 3. 相似度与自动关系

当前语义图默认 similarity TopK=30、threshold=0.86；Learning Map 自动模型关系 threshold=0.95，默认包含 rule relations、不自动包含 similarity relations。阈值测试应基于人工标注的正负关系集，报告 Precision/Recall、误连率和每节点候选数分布。

## 4. 存储参数

磁盘报告按 text-index、vector-index、deterministic-graph、semantic-facts、semantic-embeddings、mastery、recommendation-actions、assessments、exam-reports 分类。每类记录 bytes、fileCount、latestModifiedAt，并检查统计范围不会遍历无关 Vault 目录。

存储验收包括：原子写入、损坏快照拒绝、最后有效版本恢复、清理幂等、删除残留为 0、schema 不兼容时明确失败、可重建缓存不覆盖事实来源。

## 5. 设置迁移

测试 new-install、legacy、current、future-schema、字段缺失、错误类型、越界值和未知字段保留。关键指标：

- 迁移成功率和 warning 分类准确率。
- 用户偏好保留率，应为 100%。
- 多次加载/保存幂等性。
- future schema 阻断率，应为 100%，避免旧插件覆盖新数据。
- secret 明文落盘次数，应为 0；只保存 secret name。
- 影响解析、分块或 embedding 的设置变化能正确使索引失效。

`advancedSettingsExpanded` 只是 UI 偏好；它的迁移测试不能与模型配置迁移混在一起。
