# 文档解析、分块、索引与 PDF 测试参数

## 1. 当前配置基线

| 参数 | 当前默认值 | 性质 |
|---|---:|---|
| `chunkSize` | 600 字符 | 产品配置 |
| `chunkOverlap` | 120 字符 | 产品配置 |
| PDF 大小上限 | 50 MB | 资源保护配置 |
| PDF 页数上限 | 300 | 资源保护配置 |
| 自动同步 debounce | 15 s | 产品配置 |
| 自动同步最长等待 | 120 s | 产品配置 |
| 自动同步文件阈值 | 8 | 产品配置 |

分块当前按字符而非 tokenizer token 计算。测试报告必须写“字符”，避免与模型 token 混淆。

## 2. 解析正确性

| 指标 | 计算方式 | 关注问题 |
|---|---|---|
| 文件发现召回率 | 应扫描文件中实际发现的比例 | scope、扩展名和隐藏目录遗漏 |
| 解析成功率 | 成功生成 `ParsedDocument` / 合格输入文件 | 损坏文件、编码、加密 PDF |
| 文本字符覆盖率 | 正确抽取字符 / 人工金标字符 | 漏字、乱码、顺序错误 |
| 段落边界 F1 | 预测段落边界与金标的 Precision/Recall 调和平均 | 段落粘连或过度拆分 |
| locator 正确率 | 可跳转到正确文件、标题或 PDF 页的结果比例 | 引用可追溯性 |
| 重复页眉页脚去除精度 | 被删除内容中真正页眉页脚的比例 | 正文误删 |

Markdown 样本至少覆盖标题、列表、代码块、表格、Unicode、空文件和超长段落。PDF 样本至少覆盖单栏、多栏、页眉页脚、旋转页、无文字页和部分可提取页面。

## 3. PDF 当前质量参数

代码把每页字符数 `>= 40` 视为 native-text page；native-text page 比例 `< 0.25` 时标记 `likelyScanned`。当前质量分：

```text
textCoverage = nativeTextPages / totalPages
qualityScore = clamp(textCoverage - multiColumnPenalty, 0.05, 1)
multiColumnPenalty = 0.12
```

这些是启发式产品参数，需要通过带金标的 PDF 集合评估误报率和漏报率。推荐记录：扫描件检测 Precision/Recall、阅读顺序准确率、空页识别率、每页耗时 P50/P95、峰值内存、取消响应时间。OCR、表格、图片和公式尚未实现，对应指标应记为 `not-applicable` 或未来计划。

## 4. 分块质量

- **长度合规率**：不超过 chunkSize 的 chunk 比例，应为 100%，特殊保留规则需单列。
- **空 chunk 率**：应为 0。
- **边界完整率**：关键答案没有被切断到无法检索的样本比例。
- **重复率**：overlap 造成的重复字符 / 索引总字符；越低不一定越好，要和 Recall 一起看。
- **稳定 ID 率**：未变化内容在增量重建后保持相同 ID 的比例。
- **溯源完整率**：包含 documentId、filePath、headingPath、locator 的 chunk 比例，应为 100%。

对 `chunkSize` 和 `chunkOverlap` 做 2×3 或 3×3 消融实验，同时比较 Recall@K、索引大小、构建耗时和回答引用质量，不能只选择速度最快的组合。

## 5. 索引生命周期与性能

需要测量全量构建、单文件新增、修改、重命名、删除和崩溃后恢复。核心参数：索引 chunks/s、文件扫描 P95、增量放大比、快照字节数、峰值内存、取消延迟、陈旧条目数、重复条目数、重启后恢复成功率。

一致性验收要求：删除后无孤儿 chunk；重命名后旧路径无残留；相同输入重复构建得到相同有序快照；失败不能覆盖最后一个有效快照。
