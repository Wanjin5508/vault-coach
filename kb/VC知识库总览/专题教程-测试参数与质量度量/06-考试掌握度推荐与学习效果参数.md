# 考试、掌握度、推荐与学习效果测试参数

## 1. 考题生成与范围

- scope precision：题目实际来源处于用户选择范围内的比例，应为 100%。
- source grounding rate：每题具有可验证 source chunk 的比例。
- 重复题率：规范化后重复问题 / 总问题。
- 可答率：仅根据选定材料能够回答的问题比例。
- 题型合法率：simple 模式只能生成 single-choice/true-false，应为 100%。
- 选项有效率：无空选项、重复 ID、重复规范化文本，且正确选项存在。
- 难度分布偏差：实际 basic/intermediate/advanced 分布与 blueprint 的差异。

## 2. 自动评分

客观题要测评分准确率、确定性和边界输入。自由回答需要人工金标集，报告 evaluator 与人工的一致率、误判率和置信度校准。不能只用模型自己生成题、答案并评分后宣称准确。

## 3. 掌握度算法参数

当前 `mastery/v2` 使用：每日衰减 0.03；难度权重 0.8/1.0/1.2；mastered score ≥ 0.85 且 confidence ≥ 0.60；趋势变化阈值 0.10。分级还包含 weak `<0.45`、developing `<0.70`、proficient 和 mastered。

测试应覆盖：

- **绑定率**：Assessment 中成功绑定到唯一 concept 的比例。
- **歧义率/未绑定率**：需要单列，不能按 0 分处理。
- **重算确定性**：相同事实输入得到完全相同快照。
- **增量等价性**：增量重算与全量重算结果相同。
- **校准误差**：例如 confidence 约 0.8 的样本实际正确比例是否接近 0.8，可用 ECE 或分桶表。
- **时间衰减敏感性**：固定证据在 1/7/30/90 天后的状态变化。
- **趋势准确率**：人工构造 improving/stable/declining 序列验证。

## 4. 自适应考试和推荐

自适应考试当前最多 10 题，每目标最多 3 个 source chunks，低置信阈值 0.45，冷却期 7 天。推荐当前最多展示 5 个主要项目，低置信阈值同为 0.45，近期评估窗口 7 天。

这些 tier 权重是排序策略，不是概率。修改权重时必须提升相应算法版本并运行排序回归测试。

推荐离线指标可使用 Precision@K、nDCG@K、重复率、已完成内容误推荐率、应复习目标覆盖率、顺序稳定性。产品验证还应记录 recommendation acceptance rate、完成率和延后率，但这些行为指标需要用户同意后以隐私友好的本地聚合方式收集。

## 5. 学习效果

真正的学习效果需要前测/后测、间隔复测和足够样本。可记录分数变化、知识保持率、完成时间和效应量；没有对照设计时只能描述相关性，不能声称插件导致提升。
