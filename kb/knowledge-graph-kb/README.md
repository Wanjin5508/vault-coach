# 知识图谱：从理论到 Knowledge Engine

这是一个独立维护的中文知识库，以“先理解，再构建，最后运营”的顺序讲解知识图谱。它不依赖本仓库的插件实现，也不把插件作为案例；实践章节选取具有代表性的开放数据和开源项目。

## 读者与目标

- **初学者**：建立图、实体、关系、本体、推理与检索的共同语言。
- **数据/搜索工程师**：能选择存储、设计索引、构建抽取与融合流水线。
- **产品和架构负责人**：能把知识图谱作为可治理、可解释、可运营的 Knowledge Engine 能力来规划。

完成后，应能回答四个问题：

1. 什么问题适合用图而不是表、文档或纯向量库解决？
2. 如何把异构数据变成带证据、版本和置信度的知识？
3. 怎样让常见查询在规模、时效和成本之间取得平衡？
4. 如何让图谱为搜索、问答、推荐、风控、数据治理等产品提供可信服务？

## 使用约定

- `事实`、`证据`、`推断`、`预测`必须分层保存，不能把模型分数伪装成确定事实。
- 例子以 `研究者—论文—机构` 小型图谱贯穿；其中名称与标识符仅作教学用途。
- 版本会快速变化的命令和产品能力，以各章节及 [[参考资料]] 中的官方文档为准。
