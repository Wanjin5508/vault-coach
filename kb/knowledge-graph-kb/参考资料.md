# 参考资料

本知识库优先链接规范、开源项目的官方文档和原始研究资料。访问日期：2026-07-24。具体命令、兼容版本和许可请以链接中的当前文档为准。

## 标准与语义基础

- [RDF 1.1 Concepts and Abstract Syntax — W3C Recommendation](https://www.w3.org/TR/rdf11-concepts/)
- [SPARQL 1.1 Query Language — W3C Recommendation](https://www.w3.org/TR/sparql11-query/)
- [OWL 2 Web Ontology Language Primer (Second Edition) — W3C](https://www.w3.org/TR/owl2-primer/)
- [Shapes Constraint Language (SHACL) — W3C Recommendation](https://www.w3.org/TR/shacl/)

## 学术综述与研究入口

- [Hogan et al., Knowledge Graphs, ACM Computing Surveys](https://doi.org/10.1145/3447772) — 适合作为知识图谱定义、生命周期与研究问题的综述入口。
- [Malkov & Yashunin, Efficient and Robust Approximate Nearest Neighbor Search Using Hierarchical Navigable Small World Graphs](https://arxiv.org/abs/1603.09320) — HNSW 的原始论文。
- [Microsoft GraphRAG](https://github.com/microsoft/graphrag) — 图增强检索生成的开源实现与文档入口；应将其输出纳入本库所述的证据、评估和治理机制。

## 建议的阅读组合

1. 先读 RDF、SPARQL、SHACL，配合 Wikidata/Jena 的小练习。
2. 再读 Neo4j/JanusGraph 的索引文档，并亲自查看查询计划。
3. 最后阅读 HNSW、OpenSearch/Milvus 和 GraphRAG，始终用证据、权限、版本和离线评估约束语义检索。
