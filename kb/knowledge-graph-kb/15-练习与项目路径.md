# 15 练习与项目路径

## 练习 1：问题驱动建模

为“研究成果发现”写 10 个问题，其中至少包含：一跳查找、两跳关联、时间过滤、来源追溯和权限过滤。为每个问题标记：起点、关系、选择性过滤、返回证据和 SLO。

验收：任何人都能据此判断某字段是属性、实体、关系还是事件，并写出查询草图。

## 练习 2：RDF、SHACL 与 SPARQL

1. 用 Turtle 描述 10 篇论文、作者、机构和主题。
2. 写一个 Shape，要求论文至少有标题和一名作者。
3. 以 Jena/Fuseki 载入，写三条 SPARQL：作者论文、机构主题、带来源的断言。
4. 故意制造三个错误，确认验证报告可以定位源记录。

验收：数据错误不会静默进入发布图。

## 练习 3：属性图、约束与索引

1. 将同一域建成 Neo4j 属性图，使用稳定 `id` 约束。
2. 写一个从唯一 ID 起步的两跳 Cypher 查询，查看执行计划。
3. 分别测试范围、全文、向量候选（可使用模拟 embedding）的适用问题。
4. 用 RRF 合并两种检索的排名，并记录所有版本。

验收：能解释每个索引服务的查询模板和写入成本。

## 练习 4：实体解析挑战

准备带同名、别名、缺失机构和不同日期格式的 100 条人物记录：

- 设计 blocking 键；
- 给匹配规则写正例/反例；
- 设定自动合并、人工审核、拒绝三档；
- 保存合并证据和撤销操作。

验收：错误合并可以完整拆回，且不会丢失原始记录。

## 期末项目：一个小型 Evidence-first Knowledge Engine

范围限定为一个公开数据集或一组自有的非敏感样本：

```text
源文件 → 解析块 → 候选实体/关系 → 证据化断言
      → 验证/审核 → 规范图 → 文本/向量索引 → 带引用查询 API
```

提交内容：模式图、数据契约、导入脚本、10 条回归查询、质量报告、索引设计、评估集、权限/删除策略及一页架构决策记录。评分重点不是图的大小，而是可解释性、可复现性、质量与任务效果。
